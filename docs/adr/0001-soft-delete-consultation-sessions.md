# 用户删除咨询会话采用软删除

心理健康场景下，咨询记录可能是危机干预的参考依据，用户不应有能力使其彻底消失。DELETE 端点只置 `deleted` 标志：会话从用户端列表消失，记录保留，管理端仍可查看（界面带"用户已删除"标记），且已删除的会话拒绝新消息（stream 与消息写入均校验）。

## Considered Options

- 硬删除（级联删消息）：被否决——抹掉了管理端的审计视角，且"列表里消失了却在后台继续产生消息"的行为不自洽。

## Consequences

- 用户端所有会话查询需过滤 `deleted`；管理端查询不过滤但需返回删除标记。
- stream 端点的归属校验顺带承担"会话是否已删除"的判断。
