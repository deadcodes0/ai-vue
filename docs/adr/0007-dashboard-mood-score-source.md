# 看板平均情绪分的聚合源采用自评情绪分

看板（GET /api/data-analytics/overview）的 avgMoodScore 与 emotionTrend 图表，聚合源定为情绪日记的自评情绪分（用户主观评分 1-10），不采用会话情绪分析产出的情绪强度（0-100）。两套度量语义不同（主观自评 vs AI 客观评估），量纲不同（1-10 vs 0-100），混用会产出无意义数字。

## Considered Options

- 会话情绪分析的评分：被否决——分析结果是懒计算+缓存的快照（ADR-0004），时效性弱、覆盖面依赖用户是否触发分析；且 0-100 量纲与日记 1-10 无法合并。
- 两者合并取均值：被否决——覆盖面广但量纲不一致，加权规则任意，且趋势图的 recordCount（日记条数）语义会断裂。
- 情绪日记的自评情绪分：用户主动记录、天然带日期维度，按日聚合即得趋势；与"同一日期可写多条"的日记模型自洽。

## Consequences

- emotionTrend 的 avgMoodScore 为当日全部日记自评情绪分的算术平均，recordCount 为当日日记条数。
- 看板指标反映的是用户主观陈述的情绪，而非 AI 评估的情绪——两套口径在产品上并存（看板看自评，会话/日记详情看 AI 分析），不互相校准。
- 改换聚合源会断裂历史看板数据的对比连续性，如需变更应出新指标字段而非复用 avgMoodScore。
- 活跃用户（activeUsers）同窗定义为近 7 天有会话或日记行为的去重用户，见 CONTEXT.md 数据分析域。
